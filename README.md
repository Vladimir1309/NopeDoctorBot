# 🤖 Бот-комбайн: Автозапись к врачу (СПб Больница РАН)

![Python](https://img.shields.io/badge/python-3.8+-blue.svg)
![Status](https://img.shields.io/badge/status-active-success.svg)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg)
![VK API](https://img.shields.io/badge/API-VKontakte-blue.svg)

Скрипт для автоматического мониторинга и **мгновенной записи** к врачам на сайте СПб больницы РАН (`my.spbkbran.ru`). Бот работает в фоне, обходит защиту сайта, автоматически заполняет форму и присылает уведомления в ВКонтакте.

> [!IMPORTANT]
> **Скрипт написан исключительно для сайта `my.spbkbran.ru`** (платформа medis.tech). 
> Структура HTML-кода, названия полей и логика работы формы (включая редирект на `/orders/pay/`) уникальны для этой больницы. Для других клиник скрипт потребует переписывания парсера.

---

## ✨ Ключевые возможности

* 🎯 **Мониторинг любых дат:** Бот перебирает заданный список дат. 
* ⚡ **Автоматическая запись:** Как только появляется свободное время, бот мгновенно переходит по ссылке, определяет ID услуги, подставляет ваш комментарий и отправляет форму.
* 🌙 **«Турбо-режим»:** С 23:58 до 00:05 бот переходит в режим повышенной готовности (пинг каждые 3 секунды), чтобы поймать номерки, которые выбрасывают в полночь.
* 🛡️ **Обход защит:** Скрипт корректно передает CSRF-токены, заголовки Referer и проходит по цепочке редиректов, чтобы заявка гарантированно зафиксировалась в Личном кабинете.
* 💬 **Уведомления в ВК:** Отправляет отчеты о статусе работы и успешной записи напрямую в ваши сообщения ВКонтакте.

## 🛠️ Как настроить под ЛЮБОГО врача и ЛЮБОЕ время

Скрипт абсолютно универсален. Чтобы перенастроить его на другого специалиста, вам нужно изменить всего несколько переменных в начале кода.

### 1. Ссылка на врача (`BASE_PTASHNIKOV_URL`)

Зайдите на страницу нужного врача на сайте, нажмите на любую дату (даже если на ней нет мест) и скопируйте ссылку из адресной строки. Обрежьте её так, чтобы в конце осталась только дата. 

```python
# Пример для Пташникова:
BASE_PTASHNIKOV_URL = "https://my.spbkbran.ru/ru/schedule/1/3/-1/0/20001494/-1/568421/"
```

### 2. Список дат (`TARGET_DATES`)

Впишите в список те даты, за которыми нужно следить (формат `ГГГГ-ММ-ДД`):

```python
TARGET_DATES = ["2026-11-09", "2026-11-16", "2026-11-23"]
```

### 3. Время приема (Опционально)

По умолчанию бот хватает **самый первый** (самый ранний) освободившийся слот. Если вам нужно строго определенное время (например, только с 15:00), в функции `find_slots_on_date` можно добавить проверку: `if text.startswith("15:"):`.

### 4. Ваш комментарий (`MY_COMMENT`)

Бот автоматически вставит этот текст в поле «Комментарии к приему» при записи.

## 🚀 Установка и запуск

**Шаг 1. Установка Python**
1. Скачайте установщик с [python.org](https://www.python.org/downloads/).
2. Запустите его. **Критически важно:** поставьте галочку **«Add python.exe to PATH»**.
3. Нажмите «Install Now».

**Шаг 2. Установка библиотек**
Откройте командную строку (`Win + R` -> `cmd`) и введите:
```bash
pip install requests beautifulsoup4 vk_api
```

**Шаг 3. Получение токена ВК и ID**
1. Создайте сообщество ВК. В настройках перейдите в **Работа с API** -> создайте ключ доступа (с правами на сообщения).
2. Узнайте свой личный ID (цифры в адресной строке вашей страницы, например `vk.com/id12345678`).
3. Напишите своему сообществу любое сообщение в ЛС (чтобы диалог открылся).
4. Вставьте данные в переменные `VK_TOKEN` и `VK_USER_ID`.

**Шаг 4. Получение Cookies (Куки)**
Для записи бот должен быть авторизован (как вы в браузере).
1. Зайдите на сайт больницы, авторизуйтесь в Личном кабинете.
2. Нажмите `F12` (DevTools) -> вкладка **Network** (Сеть).
3. Обновите страницу (`F5`). Нажмите на первый запрос в списке.
4. В панели справа найдите **Request Headers** -> строку **Cookie**.
5. Скопируйте всю строку и вставьте её в переменную `MY_COOKIES` в коде.

*(Внимание: куки живут несколько дней. Если бот перестанет записывать, просто обновите их по этой же инструкции).*

## 🖥️ Как оставить работать 24/7

1. **Запрет сна:** Ночью компьютер не должен уходить в спящий режим. Зайдите в *Панель управления -> Электропитание* и поставьте «Переход в спящий режим: Никогда».
2. **Запуск:** Откройте папку со скриптом, кликните в адресную строку, введите `cmd` и нажмите Enter. Напишите `python имя_скрипта.py`.
3. Вы можете просто **свернуть окно консоли** в панель задач. Бот будет работать в фоне, не нагружая процессор.
